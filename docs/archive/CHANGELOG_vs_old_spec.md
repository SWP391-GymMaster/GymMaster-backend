## 4. `docs/init/15_DATABASE_SCHEMA.md` — SỬA KHỚP CODE (quan trọng cho team DB)

- Tên bảng **snake_case** (`users`, `member_profiles`...).
- `Id` = **BIGINT**.
- **Bỏ `RoleId`** trên users → dùng bảng **`user_roles`** (nhiều-nhiều).
- Thêm bảng **`password_reset_tokens`**.
- `users.Status` = **chuỗi** `'active'`/`'locked'` (không TINYINT).
- `LockoutUntil` → **`LockedUntil`** + thêm **`LoginWindowStartedAt`**; bỏ `RowVersion`.
- Đánh dấu rõ bảng **✅ ĐÃ CODE** vs **⬜ THIẾT KẾ** (spec 003–008).
- Tạo thêm **`docs/archive/DB_DIFF_FOR_DBTEAM.md`** (so sánh CŨ vs MỚI cho bạn DB).
