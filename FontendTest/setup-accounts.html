Bước 1 — Đăng nhập Admin

Token Admin sẽ được dùng để tạo PT và Member ở các bước tiếp theo.

POST /api/v1/auth/login

Token Admin (tự điền sau login)

Lưu ý: Token chỉ hợp lệ 15 phút. Nếu quá hạn, login lại và token sẽ tự cập nhật.

Bước 2 — Admin tạo tài khoản User cho PT

Tạo User với role pt. Hệ thống sẽ trả về userId dùng ở bước 3.

POST /api/v1/users  |  [Admin]

Kết quả — PT User ID

Lưu ý: Bước này chỉ tạo tài khoản đăng nhập. Bước 3 sẽ tạo hồ sơ PT (TrainerProfile) kèm thông tin chuyên môn.

Bước 3 — Tạo hồ sơ PT (TrainerProfile)

Gắn thông tin chuyên môn vào userId vừa tạo. Hệ thống trả về Trainer Profile ID dùng khi phân công.

POST /api/v1/trainers  |  [Admin]

Kết quả — Trainer Profile ID

✅ Hồ sơ PT đã tạo xong. PT có thể đăng nhập bằng email

Bước 4 — Tạo tài khoản Member

Chọn 1 trong 2 cách: Admin tạo trực tiếp (khuyên dùng) hoặc Member tự đăng ký.

POST /api/v1/members  |  [Admin / Staff]
Cách này tạo User + MemberProfile trong một bước. Ngay sau đó có Member Profile ID để dùng.
POST /api/v1/auth/register  |  [Public]
Cách này tạo tài khoản Member. Sau đó cần thêm 1 bước để tạo MemberProfile (Admin dùng token).

Bước 4a — Member tự đăng ký

Bước 4b — Admin tạo MemberProfile cho tài khoản vừa đăng ký

POST /api/v1/members  |  [Admin]
Điền lại đúng email vừa đăng ký để liên kết với tài khoản đó. Không cần password.

Kết quả — Member Profile ID

Các bước tiếp theo để test

  1. Mở pt-training.html → Đăng nhập với Admin token
  2. Vào Phân công PT → dùng Member Profile ID + Trainer Profile ID vừa tạo
  3. Đăng nhập lại bằng tài khoản PT (email + mật khẩu ban đầu) → lấy token PT
  4. Dán token PT vào ô token → Xem danh sách Member của tôi
  5. PT Tạo Giáo án cho member vừa phân công
  6. PT Ghi chú luyện tập cho member
  7. Đăng nhập bằng tài khoản Member → PT xem giáo án và ghi chú của mình
